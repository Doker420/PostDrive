# 📣 РУПОР — биржа рекламы для Telegram и VK

Полноценная ads-площадка RU-сегмента: владельцы каналов, чатов и ботов
публикуют свои площадки с ценами за размещение рекламы, рекламодатели
ищут их через фильтры и покупают с эскроу-защитой средств.

**Подробный план реализации:** [`docs/PLAN.md`](docs/PLAN.md)

## Возможности (MVP)

- 📇 **Каталог площадок** — Telegram/VK, каналы/чаты/боты, категории,
  фильтры (платформа, тип, цена, подписчики), поиск, сортировки, пагинация.
- 💰 **Публичный прайс** владельца: пост 24/48/72 ч, репост, нативный пост.
- 🛡️ **Эскроу-заказы**: бронирование → приём → публикация → подтверждение →
  выплата владельцу (комиссия 10%); отказы — авто-возврат; споры — арбитраж.
- 👤 **Личный кабинет**: площадки, продажи, закупки, баланс, история операций.
- 💳 **Пополнение баланса**: **CryptoBot**, **xRocket**, **ЮMoney** +
  демо-режим без ключей.
- ⭐ **Отзывы** только от реальных завершённых заказов.
- 🛡️ **Админ-панель**: модерация, пользователи, транзакции, споры, метрики.

## Быстрый старт

```bash
cd rupor
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python seed.py --force   # демо-данные (сбрасывает базу!)
.venv/bin/python run.py            # http://localhost:8000
```

Демо-аккаунты (создаются сидом):

| Роль | Логин | Пароль |
|---|---|---|
| Админ | `admin@rupor.ru` | `admin1234` |
| Владелец | `owner@rupor.ru` | `owner1234` |
| Рекламодатель | `advertiser@rupor.ru` | `adv1234` |

## Конфигурация

Скопируйте `.env.example` → `.env` и заполните. Ключевое:

| Переменная | Описание |
|---|---|
| `SECRET_KEY` | секрет приложения (обязательно в проде!) |
| `BASE_URL` | публичный адрес — от него зависят ссылки оплаты и вебхуки |
| `COMMISSION_PCT` | комиссия площадки с завершённых заказов (10) |
| `CRYPTOBOT_TOKEN` | токен Crypto Pay (@CryptoBot → Crypto Pay → Create App) |
| `XROCKET_TOKEN` | токен xRocket Pay (pay.xrocket.eu) |
| `YOOMONEY_PURSE` / `YOOMONEY_SECRET` | кошелёк ЮMoney и секрет HTTP-уведомлений |
| `USDT_RUB_RATE` | курс конвертации рублей в USDT для крипто-пополнений (95) |

**Демо-режим платежей:** пока токены не заданы, пополнение работает
виртуально (кнопка «Оплатить (демо)») — удобно для локальной разработки.

**Вебхуки:** `/pay/cryptobot/webhook`, `/pay/xrocket/webhook`,
`/pay/yoomoney/notify` — пропишите их в кабинетах провайдеров.

## Структура

```
rupor/
├── app/
│   ├── main.py          # сборка FastAPI
│   ├── config.py        # env-конфигурация
│   ├── db.py            # SQLite, схема, деньги в копейках
│   ├── auth.py          # пароли, сессии, CSRF, флеш
│   ├── payments.py      # CryptoBot / xRocket / ЮMoney
│   ├── formats.py       # форматы рекламы, статусы
│   ├── web/             # маршруты: public, account, admin, payhooks
│   ├── templates/       # Jinja2
│   └── static/          # CSS, JS, логотип
├── docs/PLAN.md         # подробный план развития
├── seed.py              # демо-данные
├── run.py               # запуск
└── requirements.txt
```

Python 3.11 · FastAPI · Jinja2 (SSR) · SQLite (WAL) · httpx.
Никаких сборщиков фронтенда — чистый CSS/JS, быстро и прозрачно.
