# FlowPay

Платформа для B2B-подключения магазинов и поставщиков разрешённых платёжных каналов.

> Проект находится на этапе архитектурной проработки. Подключение реальных денег, банковских реквизитов и криптовалютных выплат допускается только после проверки юридической модели, требований KYC/AML/PCI и договоров с лицензированными провайдерами.

## Текущий репозиторий

Исторически репозиторий содержит Python Telegram-бота/автопостер. Этот код пока не удаляется: он будет либо перенесён в модуль уведомлений, либо выделен в legacy-приложение. Платёжное ядро создаётся отдельно и не будет зависеть от старой SQLite-логики.

## Ближайший шаг

1. Утвердить юридическую модель и страны работы.
2. Выбрать первый платёжный провайдер/тестовый адаптер.
3. Создать backend foundation: auth, organizations, projects, API keys, migrations.
4. Добавить sandbox-платёж с идемпотентностью и webhook.
