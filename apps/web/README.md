# FlowPay web panel

Первый адаптивный интерфейс кабинета магазина: авторизация, обзор, баланс, аналитика, платежи, выплаты и безопасность.

Frontend использует относительный API URL `/api/v1`. Для отдельного dev-сервера можно задать:

```html
<script>window.FLOWPAY_API = 'http://localhost:3000/api/v1'</script>
```
