# FlowPay API

Локальный запуск из корня репозитория:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
python -m apps.api.app
```

API будет доступен на `http://localhost:3000`, Swagger — `/docs`.

Первый вертикальный срез уже включает регистрацию, логин, проекты, test/live ключи, создание платежа и идемпотентное чтение платежа. Это sandbox foundation; подключение банковских каналов и реальных выплат добавляется адаптерами после прохождения интеграционных тестов.
