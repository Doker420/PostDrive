# Fix list — версия 6.0.1

## Исправления

- Исправлено удаление аккаунта: подтверждение больше не передаёт пустой FSM-контекст и не приводит к сообщению «Внутренняя ошибка».
- В меню аккаунтов добавлен прямой переход к указанной странице.
- Прямой переход к странице добавлен также в массовый выбор аккаунтов, нейрокомментинг и выбор аккаунта для вступления в пак.
- В панель настроек отдельного аккаунта добавлена заметная кнопка «📱 К аккаунтам».
- В рассылке добавлен режим «📤 Репост из группы» с поддержкой публичных ссылок, ссылок вида `t.me/c/...` и формата `@group message_id`.
- Добавлена массовая проверка прокси всех аккаунтов пользователя. Нерабочий прокси автоматически удаляется из настроек аккаунта.
- В инвайтинге добавлен переключатель массового вступления выбранных аккаунтов в целевой чат перед приглашением пользователей.
- Сохранена работа с длинными списками аккаунтов через пагинацию без превышения лимитов Telegram; переход теперь выполняется кнопками страниц `1️⃣ 2️⃣ 3️⃣ 4️⃣`.
- В меню проверки прокси добавлены массовая смена BIO, массовое вступление по ссылкам и массовая проверка спамблока.
- В массовых операциях рассылки, инвайтинга, вступления и проверки спамблока добавлена кнопка «☑️ Выбрать все аккаунты»; для нейрокомментинга доступен массовый запуск всех выбранных аккаунтов.
- На главную добавлен раздел «📣 Кампании» с быстрым доступом к рассылке, инвайтингу, вступлению, проверке спамблока, нейрокомментингу и аккаунтам.
- Добавлена установка и смена Telegram 2FA: для обычного подключения, после массового импорта и в панели аккаунта; пароли не сохраняются.
- Polling и временные сетевые сбои Bot API теперь автоматически восстанавливаются, чтобы после простоя не требовалось несколько раз нажимать `/start`.
- Временный cooldown/статус ограничения автоматически сбрасывается после `restricted_until`; постоянные ограничения, бан и ошибка прокси не очищаются автоматически.
- API-пары аккаунтов распределяются из большого пула `hashs.txt` в формате `api_id:api_hash`.
- В настройках рассылки добавлен переключатель «🗑 Удалять у себя»: после успешной отправки сообщение удаляется из истории аккаунта-отправителя для обычного текста, фото, репоста и @PostBot; ошибка удаления не отменяет успешную доставку.
- Добавлен «Центр здоровья аккаунтов»: история проверок, latency, FloodWait/cooldown, ошибки сессии и автоматическое исключение нездоровых аккаунтов из новых кампаний.
- Массовый ZIP-импорт получил dry-run-предпросмотр, реестр import-run и подробный отчёт до фактического добавления аккаунтов.
- Добавлен пользовательский blacklist/opt-out с TXT-импортом; цели автоматически исключаются из рассылки и инвайтинга, а команды «стоп»/«отписка» учитываются автоответчиком.
- Добавлены черновики кампаний, история operation reports и журнал аудита действий пользователя.
- Добавлена безопасная metadata-only резервная копия без session string, API hash и proxy credentials.
- Добавлено опциональное шифрование session string и API hash через `SESSION_ENCRYPTION_KEY`/Fernet; ключ хранится только в окружении.

## Формат `hashs.txt`

```text
123456:api_hash_1
234567:api_hash_2
# комментарии и пустые строки разрешены
```

Файл содержит секреты и добавлен в `.gitignore`. Пары назначаются аккаунтам и сохраняются в базе данных.
